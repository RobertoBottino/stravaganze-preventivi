# Stravaganze Floreali - Preventivi PWA

PWA per creare preventivi matrimoniali di Stravaganze Floreali da iPhone, Android e computer, senza App Store o Play Store.

## Funzioni

- archivio locale di più matrimoni;
- autosalvataggio sul dispositivo tramite IndexedDB;
- campi per sposi, cerimonia, ricevimento, data evento e contratto;
- calcolo automatico delle date dell'8° e 7° giorno antecedente l'evento;
- pagine dinamiche della proposta con fino a 3 foto per pagina;
- tabella preventivo tipo Excel con quantità e prezzo unitario;
- manodopera percentuale configurabile;
- IVA configurabile, preimpostata al 22%;
- caparra e saldo calcolati automaticamente;
- bonus/omaggi;
- 7 pagine Storybrand statiche;
- 2 pagine statiche di testimonianze;
- contratto completo con firme;
- generazione PDF interamente nel browser;
- condivisione nativa del PDF quando supportata;
- backup/importazione JSON della singola bozza;
- funzionamento offline dopo il primo caricamento completo.

## Ordine del PDF

1. Storybrand;
2. pagine dinamiche della proposta;
3. riepilogo preventivo;
4. testimonianze;
5. contratto e firme.

## Installazione come app

Dopo la pubblicazione su GitHub Pages:

### iPhone / iPad

Aprire il sito in Safari → Condividi → **Aggiungi alla schermata Home**.

### Android

Aprire il sito in Chrome → menu → **Installa app** / **Aggiungi a schermata Home**.

## Dati e privacy

Le bozze e le immagini caricate restano nel database locale del browser. Non viene usato un server applicativo. È consigliato usare il pulsante Backup per le bozze importanti.
